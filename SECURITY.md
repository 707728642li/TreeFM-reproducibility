# Security and confidential-review policy

This repository is private during peer review.

Report accidental inclusion of credentials, personal identifiers, private paths, unpublished manuscript text, or restricted data to the repository owner without opening a public issue. Rotate any exposed credential immediately and remove it from Git history before public release.

Raw sequencing data and public genomes must be downloaded from their authoritative repositories. Do not redistribute controlled or license-restricted inputs through this repository.
