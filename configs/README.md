# Configuration snapshots

These JSON files preserve analysis settings and thresholds used by the code modules. Machine-specific roots are not authoritative and must be provided at runtime through `TREEFM_ROOT`, `PUBLIC_GENOME_ROOT`, or script arguments.

Historical contracts in `docs/protocols/` remain the authority for whether an analysis was prospective, amended, or post-hoc. A configuration filename containing `freeze` does not by itself establish prospective status.
